# Unsplash Image Search App

A fast, responsive React application built with Vite that allows users to search for images using the Unsplash API and displays them in a grid layout.

## Features

- 🔍 **Real-time Image Search:** Search high-resolution photos via the Unsplash API.
- ⚡ **Vite + React:** Built with Vite for instant server start and lightning-fast HMR.
- 🛡️ **Secure API Access:** Pass API keys directly via environment variables without committing secrets to repository code.
- ⌨️ **Keyboard Support:** Trigger search by pressing the `Enter` key.

---

## Tech Stack

- **Frontend:** React (JSX, Hooks)
- **Styling:** CSS3
- **API:** [Unsplash API](https://unsplash.com/developers)
- **Build Tool:** Vite

### Prerequisites

- Node.js installed on your system.
- An **Access Key** from your [Unsplash Developer Dashboard](https://unsplash.com/developers).
